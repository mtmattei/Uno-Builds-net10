4. Gap Analysis Action Required

🔴 Bugs Found in Existing Code

IssueSeverityLocationDetails
Material multi-line action button unnamed Bug Material/v2/Snackbar.xaml The multi-line action button in the Material style is missing x:Name="PART_ActionButtonMultiLine". It won't be wired for click events. The default template has the same issue.
Material Dark theme missing Bug Material/v2/Snackbar.xaml Only Default and Light theme dictionaries exist. The Dark theme is missing, meaning dark mode will fall back to Default (which uses light-theme M3 inverse tokens). M3 inverse colors flip between themes.
SnackbarHost outer Grid comment claims clip but doesn't clip Minor SnackbarHost.xaml Comment says "clips the slide-in animation" but no ClipToBounds or Clip is set. The slide-up animation may be visible outside the host bounds on some platforms.

🟢 Implementation Quality Review

AreaStatusNotes
Core Snackbar visual Solid Clean template parts wiring, proper unwire in OnApplyTemplate, visual states work correctly. Dual-layout (inline + multiline) is the right pattern.
Accessibility / AutomationPeer Solid SnackbarAutomationPeer exposes as StatusBar control type. AutomationProperties.LiveSetting="Assertive" on message TextBlock — screen readers will announce. Dismiss buttons have AutomationProperties.Name. Escape key handling present.
SnackbarHost queue + lifecycle Solid TaskCompletionSource pattern is correct. Queue with MaxQueueSize cap. CancellationToken-based timer. Proper cleanup of event handlers.
Animations Solid Storyboard-based enter/exit with slide + fade. StopRunningAnimations follows DrawerControl's Pause→snapshot→Stop→restore pattern. Swipe snap-back animation.
Thread safety Good DispatcherCompat usage for timer callbacks. ProcessQueue guards with _isAnimating. ShowAsync is UI-thread-only (correct for WinUI control).
SnackbarDismissReason enum Good addition Not in original plan but valuable — callers can distinguish timeout vs user action vs replaced. Matches Compose SnackbarResult pattern.
SnackbarDuration constants Good addition Short/Long/Indefinite as static TimeSpan fields. Clean, discoverable API.
Swipe-to-dismiss Solid ManipulationDelta/Completed handlers with 1/3 threshold, opacity fade, snap-back animation.
DependencyProperty patterns Consistent Follows toolkit convention: #region blocks, static property, PropertyMetadata with callbacks, IS_WINUI conditionals.
Material 3 theming Good Uses StaticResource aliasing to Material tokens (InverseSurfaceBrush, BodyMediumFontSize, etc.). Typography tokens for both message and action.
Lightweight styling Comprehensive Full set of overridable ThemeResource keys for background, foreground, corner radius, dimensions, typography.
Runtime tests Good coverage Tests for: default state, action visibility, dismiss, auto-dismiss, queue processing, max queue, indefinite duration, action command.
Documentation Complete Full doc with properties tables, XAML + C# examples, SnackbarDismissReason explanation, lightweight styling guide.

🔵 Edge Cases & Hardening Considerations

ConsiderationStatusRecommendation
ShowAsync before template applied Consider If ShowAsync is called before OnApplyTemplate completes, _isReady will be false and ProcessQueue returns early. Items will be queued but never displayed. Consider adding a deferred processing call in OnApplyTemplate.
SnackbarHost removed from tree mid-show Consider If the host is unloaded while showing, pending TCS tasks will never complete. Consider completing with a Cancelled-like reason on Unloaded, or use CancellationToken.
Re-entrancy in DismissCurrent → ProcessQueue Handled The _isAnimating guard and deferred ProcessQueue via dispatcher prevents re-entrancy. Good pattern.
SafeArea integration Future Plan mentions SafeArea integration but it's not implemented. The SnackbarHostMargin provides basic offset. True SafeArea would need dynamic bottom inset on iOS/Android. Can be a follow-up.
